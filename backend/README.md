# Orion AI Copilot — Backend Service

Backend API connecting Orion VFFS industrial machines with Gemini Multimodal RAG and Supabase.

---

## 1. Database & Storage Setup

### A. Run Database Migrations
1. Open your project on the [Supabase Dashboard](https://supabase.com/dashboard).
2. Navigate to the **SQL Editor**.
3. Run [`migrations/001_initial_schema.sql`](./migrations/001_initial_schema.sql). This executes:
   - `pgcrypto`, `vector`, and `pg_trgm` extensions.
   - Dual 1536-dim vector columns (`text_embedding`, `image_embedding`) with HNSW indexing.
   - Generated `search_tsv` for native full-text search.
   - Tiered telemetry tables (`telemetry_latest`, `telemetry_events`, `telemetry_rollups_1m`).
   - Outbound-only edge collector ledger (`edge_devices`, `collector_records`).
   - RLS enabled with default-deny across all application tables.

### B. Storage Buckets (Private)
1. Go to **Storage** -> **Buckets**.
2. Create two **private** buckets:
   - `manual-documents` (raw PDF manuals)
   - `manual-pages` (rendered page images)
3. Access to page images is issued via short-lived signed URLs (5-minute TTL) generated by the API.

## 2. Environment Configuration
Copy `.env.example` to `.env` and provide your secrets:
```bash
cp .env.example .env
```
Required:
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `SUPABASE_DB_URL`
- `GEMINI_API_KEY`
